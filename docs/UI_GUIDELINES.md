# UI Guidelines

| Token | Värde |
| --- | --- |

## Principer
- Mörkt tema som standard
- Rundade hörn (rounded-2xl på kort)
- Mjuka skuggor
- Tydliga hover-tillstånd
- Semantiska tokens från `src/styles.css` — aldrig hårdkodade färger i komponenter
