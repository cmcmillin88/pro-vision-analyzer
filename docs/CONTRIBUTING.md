# Contributing

## Kodstil
- TypeScript överallt, tydliga typer
- Små, återanvändbara komponenter
- Använd semantiska design-tokens från `src/styles.css`
- Konstanter i `src/lib/constants.ts`

## Commits
Beskrivande commit-meddelanden på svenska eller engelska.

## Nya sidor
Skapa en fil under `src/routes/` — TanStack Router genererar route-trädet automatiskt.
